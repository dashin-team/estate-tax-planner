# 遺產稅・贈與稅 傳承規劃與預留稅源

一個手機優先的單頁網站：用幾個簡單的數字，看看家庭的遺產稅大約多少、現金夠不夠，以及有哪些方式可以提早安排。保險只是其中一種工具。

線上網址：https://dashin-team.github.io/estate-tax-planner/

## 內容

- 為什麼要先談稅源
- 遺產稅試算（4 組示例、115 年現行／2027 媒體推估切換）
- 贈與稅與年度贈與規劃
- 預留稅源的方式比較表
- 保險怎麼看（含保險金信託）
- 稅源缺口試算
- 真實案例（可收合，附來源連結與日期）
- 常見迷思、常見問題、說明與資料來源

## 特色

- 單一檔案 `index.html`：內嵌 CSS 與原生 JavaScript，無建置步驟、無外部 CDN／字型／網路請求，離線也能開。
- 不蒐集任何資料、沒有追蹤碼；輸入的數字只在瀏覽器內計算。
- 內建「分享」按鈕（支援系統分享，或複製連結）。

## 計算公式（金額單位：萬元）

- 課稅遺產淨額 = 遺產總額 − 免稅額 − 各項扣除額 − 債務
- 遺產稅：淨額 ≤ 5,621 → 淨額 × 10%；≤ 11,242 → 562.1 + (淨額 − 5,621) × 15%；超過 → 1,405.25 + (淨額 − 11,242) × 20%
- 建議預留現金 = 預估遺產稅 × 1.2（業界經驗法則，非法定標準）
- 贈與稅：淨額 ≤ 2,811 → 淨額 × 10%；≤ 5,621 → 281.1 + (淨額 − 2,811) × 15%；超過 → 702.6 + (淨額 − 5,621) × 20%
- 115 年數字：遺產稅免稅額 1,333、贈與稅年免稅額 244、配偶 553、直系卑親屬每人 56（未成年每年加扣 56 至成年）、父母每人 138、重度身障 693、喪葬費 138
- 2027 媒體推估：免稅額 1,487、贈與稅免稅額 272（推估值；扣除額與級距仍用 115 年數字）

資料來源：財政部 114 年 11 月 27 日公告（台財稅字第 11404671540 號），詳見網頁最下方「說明與資料來源」。
